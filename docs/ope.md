# 离线策略评估（OPE）方法说明

候选优惠策略在真正投放前，先按历史台账做离线评估。估计目标是候选策略在**可评估会话**上的单次会话净收益期望，净收益一律为 `revenue - cost`。被排除的行按原因披露，不进入任何估计分母；三个估计量共用同一可评估集合，可以直接比较。

## 记号

每行是一次会话观测：`action` 为历史实际动作，`propensity` 为行为策略选择该实际动作的概率，`candidate` 为候选策略对此会话的推荐动作，`week` 为会话周，`segment` 为投放前客群。确定性候选策略下，行权重为 `w = 1{action = candidate} / propensity`。

## 支持域检查与排除原因

逐行检查，优先级如下，每行只计入一个原因：

| 代码 | 含义 | 说明 |
| --- | --- | --- |
| `invalid_propensity` | 不合法概率 | propensity 不在 [0,1] 内（负或大于 1） |
| `zero_propensity` | 零概率 | propensity 为 0，与实际记录到的动作矛盾 |
| `insufficient_history` | 历史窗口不足 | 该行周只进入训练窗口，没有对应验证折 |
| `no_action_coverage` | 候选动作无历史覆盖 | 同一客群的训练期内从未实际投放该候选动作 |

覆盖按（客群, 动作）判定，且只看各折训练期：候选动作必须在该行所属客群、验证周之前的全部周内实际出现过。通过全部检查的行称为可评估行；`action = candidate` 的可评估行称为匹配行。

## 前向切分与交叉拟合

折按 week 向前推进：第 k 折验证第 k 个周，训练期是之前的全部周（`--min-train-weeks` 控制首个验证周之前至少累积几周）。收益模型是岭回归，特征为 segment 与 action 的哑变量（排序后的首个水平为基线，截距不惩罚）。每一折内部：

- 编码水平只来自该折训练期出现过的值；验证行遇到训练期未见的水平时回落到全零哑变量；
- 惩罚系数只在训练期内部再做前向链式验证按平均 MSE 选择（单一候选直接使用；训练期不足两周时取网格中位数并标记 `fallback_single_train_week`），不得用验证周或全量数据选模型；
- 验证行的收益预测全部来自该折模型，即时间意义上的交叉拟合。

## 估计量

记可评估行数为 N，裁剪后权重为 `w̃`，折模型对动作 a 的净收益预测为 `m̂(x, a)`：

- **IPW（逆概率加权）**：`V̂ = (1/N) Σ w̃·r`
- **SNIPS（自归一化）**：`V̂ = Σ w̃·r / Σ w̃`；权重和为零时不可用，输出 null 并给出警告
- **DR（双稳健）**：`V̂ = (1/N) Σ [m̂(x, candidate) + w̃·(r − m̂(x, action))]`，预测来自交叉拟合模型

基线是同一可评估集合上历史策略的样本均值净收益；总体净增益 = 估计值 − 基线，三者分别报告。

## 权重裁剪与有效样本数

`--clip τ` 把权重截断到 τ（默认 10，0 表示不裁剪）。决策文件的 `evaluation.weights` 披露：裁剪行数、被截断的权重占比（1 − Σw̃/Σw）、裁剪前最大权重、裁剪前后两套有效样本数 ESS = (Σw)²/Σw² 及其占可评估行的比例。裁剪只压缩权重差异，ESS 通常会上升，两个数都给出来便于判断代价。

## 区间

区间用影响函数的标准误做正态近似，置信水平由 `--confidence` 控制（默认 0.95）。可评估行不足两行时区间输出 null。小样本或权重高度集中时区间只作参考，ESS 是更直接的提示。

## 决策文件

`evaluate` 输出单一 JSON 决策文件，同一文件内包含：总体净增益与区间（三个估计量）、分客群覆盖与估计、按原因分布的排除计数（总体、分客群、分折）、裁剪与 ESS 披露、逐折的模型与覆盖明细、警告列表。估计不可用时输出 null 并保留全部排除计数，不会只展示留下来的部分。

## 复现方式

```bash
# 训练并保存交叉拟合模型（可重复执行，产物字节一致）
python3 -m analysis_app train --model output/model.json
# 加载已保存模型评估；加载前校验折结构与每折训练数据指纹
python3 -m analysis_app evaluate --model-in output/model.json --output output/decision.json
# 不加载也可以现场训练并同时保存模型
python3 -m analysis_app evaluate --model-out output/model.json --output output/decision.json
```

模型文件记录每折的验证周、训练周、训练行指纹、编码水平、惩罚系数与系数向量。加载时若当前数据的折结构或任一折训练内容发生变化，命令以退出码 2 失败，不会静默换模型。输入行序不影响任何结果：训练与评估统一按 (week, observation_id) 排序。

## 限制

- 候选策略按每行 `candidate` 视为确定性策略；随机候选策略需要另行给出候选分布。
- 无混杂假设只在给定 segment 与 week 的范围内成立，台账未记录的画像变量不在控制内。
- 区间是正态近似；极小 propensity 行即使被裁剪，估计仍可能敏感，需结合 ESS 与裁剪披露判断。
- 演示数据全部为本地合成，不能用来推断真实业务效果。
